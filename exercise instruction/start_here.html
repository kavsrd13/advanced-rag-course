Use Windows PowerShell. Install Git, Python 3.11, Azure CLI and VS Code. Reopen PowerShell after installing. A script link opens source for reading. Clone the complete repository to run the scripts with their data and dependencies.

git --version

New-Item -ItemType Directory -Path "$env:USERPROFILE\AI-Course" -Force | Out-Null
Set-Location "$env:USERPROFILE\AI-Course"

Test-Path ".\Knowledge Base\Lab_Support\metadata.csv"

Expected: the folder ends in advanced-rag-course\Labs and both checks return True. Run every command below from this folder. The UTF-8 setting prevents Windows console errors when printing model answers.

Already cloned, or returning in a new terminal?

Set-Location "$env:USERPROFILE\AI-Course\advanced-rag-course\Labs"
git pull --ff-only

Use your actual checkout path if different. Clone once; reuse it for later labs. If Git reports local edits, save your work and ask the instructor before updating. Each lab reads its own .env; Git does not supply credentials. The run commands use each virtual environment directly, so activation is optional.

For Azure operations, sign in with your assigned student account using az login, complete MFA, and select your assigned subscription. For certificate errors, follow the certificate troubleshooting steps. If PowerShell blocks setup.ps1, use Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned for this terminal, subject to organization policy.

Sign in and create or reuse resources

Use the student identity, subscription, group, region and unique tag supplied by the instructor. Complete interactive MFA when prompted. Azure subscription Owner and Foundry User are separate permissions; a working portal sign-in alone does not prove model or agent access.

az login
$SubscriptionId = Read-Host "Assigned subscription ID"
az account set --subscription $SubscriptionId
az account show --query "{subscription:id,user:user.name}" --output table
$StudentTag = Read-Host "Assigned unique student tag"
$ResourceGroupName = Read-Host "Assigned resource group name"
.\00_setup_environment\setup.ps1 -StudentTag $StudentTag -ResourceGroupName $ResourceGroupName

Run provisioning only if you need resources. If you already have working resources, select Route B in the exercise and configure its local .env. The setup script reads the assigned group’s region. Avoid changing tag/region on retries. Its generated connection file is 00_setup_environment/.env.generated. No keys are included in Git.

Use the Azure OpenAI endpoint for classic model calls, Search endpoint for indexes, and Foundry project endpoint for agents. Deployment names must match actual deployments. Vector labs expect text-embedding-3-large with 3,072 dimensions. Test a supported, small pay-per-token deployment before proceeding; quota and capacity can differ across regions.

Before running each exercise

  1. Confirm the terminal folder, Python interpreter and requirements file.
  2. Configure that lab’s own .env using actual endpoints, keys and deployment names. Save it as .env, not .env.txt.
  3. Build the data/index before running its question app. Builders may replace schemas or reload documents, so use your own index and service.
  4. Course Lab 12 and Lab 17 depend on the hybrid index from Lab 11; their Search endpoint and index name must match. Agentic RAG uses its own environment and setup.
  5. Run the supplied test prompt and inspect sources/citations. A script starting successfully does not prove the retrieved evidence is correct.
  6. For Gradio, open the local URL printed by the terminal and keep the process running. Stop it with Ctrl+C.

For typical problems: file not found → check current folder; missing module → use the correct environment; 401/403 → check identity, roles and credentials; deployment not found → check endpoint and deployment name; 429 → check quota/rate limits; certificate verification failed → follow certificate guidance and use an IT-approved CA bundle. Do not disable TLS validation.

Finish and clean up

Keep reused resources until all dependent labs are complete. Use the cleanup section in each exercise to delete only the resources you created. Confirm the selected subscription and exact group before deleting a group. Never delete another student’s or instructor’s group. Stop local apps and close Colab runtimes; preserve comparison results before rerunning evaluators. Secrets and generated data must not be committed.
