Advanced RAG Azure Lab Corpus

This fictional corpus contains six connected enterprise documents. Each document is provided in DOCX and PDF and is designed to be approximately three pages.

Recommended Azure use:
- Upload documents to Azure Blob Storage.
- Index with Azure AI Search.
- Add fields for documentId, owner, version, effectiveDate, classification, status, product, firmware, and sourceFile.
- Use Microsoft Foundry and Foundry IQ for multi-source and agentic retrieval exercises.

Intentional RAG features:
- Exact codes and control IDs: SEC-114, E-4012, KB-E-4012.
- Current and superseded policy information.
- Cross-document references and multi-hop entities.
- Tables, timelines, policies, operational metrics, and governance controls.
- Public, Internal, Confidential, and Restricted-style access scenarios.
- No-answer, citation, version-filter, and prompt-injection test opportunities.

All names, organizations, people, products, dates, and scenarios are fictional training data.
