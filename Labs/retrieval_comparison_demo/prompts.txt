NORTHSTAR IT SUPPORT: THREE RETRIEVAL PATTERNS
===========================================
All documents, people, policies and codes in this demo are fictional.
Use the SAME question and passage count for all three methods.
First turn answer generation OFF. Compare ranked evidence. Then turn it ON.
Start with 1 passage to make rank differences visible; repeat with 2 or 3.
Do not assume that hybrid always wins or compare raw score values across modes.

1. EXACT IDENTIFIER
Prompt: NS-7428
Expected useful sources: 03-scanner-recovery and 02-printer-code-catalog.
Observe: keyword search can exploit an exact, opaque code. Vector search may also
succeed, but inspect whether it confuses the nearby code NS-7429. The correct
subsystem is the scanner feed sensor, not the finishing module. This short query
is for Keyword/Vector first; semantic rankers work better with full questions.
Follow-up: What is the recovery procedure for NS-7428?

2. PARAPHRASE WITH LITTLE WORD OVERLAP
Prompt: A colleague has left the organisation. How do we stop them getting into our systems?
Expected useful source: 05-offboarding.
Observe: the file uses "employment termination", "deactivate corporate identity",
"revoke refresh tokens" and "terminate active sessions". Keyword retrieval can
miss it because the question uses different words. Vector and hybrid can connect
the meanings. The account-recovery document restores access and is not sufficient
for this question. Inspect the actual ranks rather than expecting a fixed winner.

3. EXACT CODE PLUS A PARTICULAR REQUIREMENT
Prompt: For NS-7429 after replacing the finishing module, how can I continue without losing the queued job?
Expected useful source: 01-printer-recovery.
Observe: the catalog, scanner procedure and ordinary jam guide share printer
language. The required procedure is to hold the queued job, reseat the blue latch,
run Calibrate Finisher, and resume after success. Do not clear or resend the job.
Use Hybrid + rerank and inspect "Hybrid rank before rerank" in the candidate
table. Compare the final position with the baseline fusion position.

4. CONDITIONAL POLICY WITH A PLAUSIBLE DISTRACTOR
Prompt: Can a contractor edit Restricted forecasts on a personal laptop if employee BYOD is allowed?
Expected useful source: 08-contractor-restricted.
Observe: 07-employee-byod allows a different person/data combination. Relevant
words alone do not establish permission. The correct working environment is a
company-managed workstation with an approved virtual desktop. Semantic reranking
can help prioritize the passage that answers the exact conditions.

5. EVERYDAY LANGUAGE
Prompt: I left my notebook in a taxi. Can the finder view the information stored on it?
Expected useful source: 10-device-encryption.
Observe: "misplaced portable computer" and "full-disk encryption" describe the
scenario without repeating "notebook" or "taxi". A supported answer must retain
the condition: powered off or locked, protected keys; an unlocked session differs.

6. UNSUPPORTED QUESTION
Prompt: How many days of parental leave does Northstar provide?
Expected: no document contains this answer. The model should abstain in every
mode. Vector search can still return nearest neighbors; nearest does not mean
relevant. Examine the passages rather than trusting a nonzero similarity score.

7. CONTROL QUESTION: ALL THREE MAY WORK
Prompt: How should a visitor use the guest wireless network?
Expected useful source: 12-visitor-wifi.
Observe: clear wording and a unique topic can make all methods succeed.

TEACHING SEQUENCE
1. Ask prompt 2 in Keyword mode with one passage and answer generation off.
2. Switch to Vector without changing the question or passage count.
3. Use Compare all three to inspect the three evidence lists together.
4. Try prompts 3 and 4; inspect ranking before/after hybrid reranking.
5. Turn answers on. Check citations and whether each claim occurs in evidence.
6. Increase the evidence count. Explain why more context may hide retrieval errors.
7. Finish with prompt 6: even hybrid reranking cannot invent missing source facts.

LIMITS OF THIS DEMO
There are 12 short text files, each indexed as one passage. No hidden document
boosting, hardcoded result ordering, query-specific retrieval rules, or canned
answers are used. Rankings depend on the deployed embedding model and Search
ranker. Hybrid includes two changes: fusion plus reranking. Its extra baseline
request exposes fusion order, but this is not a large benchmark or an isolated
test of reranking alone. No production authentication or document ACLs are shown.
