# Advanced RAG Course

Open the [student exercise site](https://kavsrd13.github.io/advanced-rag-course/) or browse the [index source](exercise%20instruction/index.html). It guides students from Hugging Face through Microsoft Foundry, RAG patterns, and agents.

## Folders

- [exercise instruction](exercise%20instruction/index.html): the course index, self-contained student HTML pages, and the Hugging Face notebook.
- [Labs](Labs/README.md): runnable RAG code, course PDFs, requirements, and lab instructions.
- [presentation](presentation): five PowerPoint decks for the course modules.

The numbered RAG labs use separate Azure indexes and local environment files. Follow each exercise's setup and cleanup instructions. Use Python 3.11 for the local RAG code; Microsoft-hosted exercises may require a separate Python environment.

Credentials, virtual environments, generated indexes, private student administration files, and unrelated draft documents are excluded from this public repository.
